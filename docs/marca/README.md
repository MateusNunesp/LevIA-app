# Marca LevIA

| Arquivo | Uso |
|---|---|
| `levia-simbolo.svg` | símbolo vetorial (círculo petróleo + pulso), para qualquer tamanho |
| `levia-simbolo-1024.png`, `levia-simbolo-512.png` | símbolo em PNG transparente (ícone, avatar, favicon) |
| `levia-logo-fundo-claro.png` | logo completa (símbolo + nome) para fundos claros, PNG transparente |
| `levia-logo-fundo-escuro.png` | logo completa para fundos escuros, PNG transparente |

**Cores:** petróleo `#1f6f5c` (símbolo), petróleo profundo `#12443a` (nome no fundo claro), creme `#fbfaf7`
(pulso e nome no fundo escuro). **Fonte do nome:** Atkinson Hyperlegible Bold.

O desenho é o mesmo do avatar no topo da conversa do app. Para gerar de novo: `python3 docs/marca/gerar_logo.py`
(precisa de Pillow e pycairo, e do `node_modules` instalado, de onde vem a fonte).
